TASK: Add Development-Only Clerk API Connection Test

PROJECT: Bluebird Mobile

CONTEXT:

The previous live integration test was blocked
because the Replit agent cannot access an
authenticated Clerk SDK session.

We need to run the test from the actual
Bluebird Mobile Preview after the developer
signs in through Clerk.

GOAL:

Add a temporary Development-only test button
to the existing Clerk Signed In screen.

BUTTON:

"Test Bluebird API Connection"

BEHAVIOR:

1. Show the button ONLY in Development.

2. Require an active Clerk session.

3. Do not execute any API request automatically.

4. On button click, show a confirmation dialog
   explaining that one request will be sent
   to the production Bluebird API.

5. Only after confirmation, obtain a fresh
   Clerk token using the existing getToken()
   integration.

6. Execute exactly one request:

   GET https://bluebirdjets.com/api/me

   Authorization: Bearer <Clerk session token>

7. Use the existing production API client.

8. Do not retry automatically.

9. Display only sanitized results:

   - HTTP status
   - Authentication accepted
   - isAuthenticated
   - isMember
   - isProfileComplete
   - Schema valid / invalid

10. Never display or log:
    - Clerk tokens
    - Authorization headers
    - Full API response bodies
    - Personal information

11. Handle network errors, CORS failures,
    HTTP errors, and timeouts.

12. Do not change authentication state
    or navigation based on the result.

13. Do not enable member-data access.

14. Do not modify the production backend.

15. Do not deploy.

IMPORTANT:

The button must be available only in
Development and must not appear in
production builds.

The implementation must not perform any
production API requests during development
or automated tests.

Add mocked tests and run TypeScript checks.

DELIVERABLE:

A Development-only button that allows
the developer to manually test the
existing Clerk session against the
Bluebird production API.

Do not execute the live test yourself.
