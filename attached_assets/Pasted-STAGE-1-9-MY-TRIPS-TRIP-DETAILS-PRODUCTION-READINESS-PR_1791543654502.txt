2. PRODUCTION ID COMPATIBILITY
==================================================

The production backend uses numeric empty-leg IDs.

Examples:

21623
21612

The existing mobile UI may use local string IDs.

Prepare the UI and navigation models to support
production numeric flight/leg IDs safely.

Requirements:

- Preserve production IDs without modification.
- Do not convert production IDs to local fixture IDs.
- Do not invent trip IDs.
- Do not assume tripId and legId are interchangeable.
- Validate route parameters.
- Handle invalid IDs gracefully.

Do not fetch authenticated production trip data.
