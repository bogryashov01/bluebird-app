4. REAL NOTIFICATION PREFERENCES
==================================================

Main Bluebird stores preferences in:

user_profiles.notification_prefs

Read via:

GET /api/me/profile

Save via:

PUT /api/me/profile

There is no dedicated notification-preferences
PATCH endpoint.

Supported fields:

notificationPrefs.mode:
- off
- all
- specific

notificationPrefs.allChannels:
- email
- sms
- both
- null

notificationPrefs.emptyLegHomeAirport:
- email
- sms
- both
- null

notificationPrefs.departingFavorite:
- email
- sms
- both
- null

notificationPrefs.arrivingFavorite:
- email
- sms
- both
- null

notificationPrefs.queueUpdates:
- email
- sms
- both

notificationPrefs.winningNotifications:
- email
- sms
- both

Do not send unsupported values.

Do not invent additional preference fields.
