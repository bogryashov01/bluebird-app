TASK 2 — QUEUE POSITION

Connect GET /api/empty-legs/:id/queue.

The API returns an array:
[
  {
    position,
    initials,
    tier,
    hasLineSkip,
    isViewer
  }
]

Use isViewer to identify the current member.

Do not calculate queue ranking locally.

TASK 3 — JOIN QUEUE

Connect POST /api/empty-legs/:id/queue.

Default request body:
{}

Handle:
- Successful join
- Incomplete profile
- Inactive membership
- Closed queue
- Same-day queue conflict
- International pass requirement
- Insufficient credits

Display actual server errors.

TASK 4 — LEAVE QUEUE

Connect DELETE /api/empty-legs/:id/queue.

Handle:
- Successful leave
- Missing participation
- Closed queue

Do not promise credit refunds.

TASK 5 — SKIP THE LINE

Support only the existing credit-based flow:

POST /api/empty-legs/:id/skip-line

Body:
{"useCredit":true}

IMPORTANT:
- Credit redemption is irreversible.
- Require explicit user confirmation.
- Never automatically retry after network ambiguity.
- Do not enable the cash-labelled branch.
- Respect queue closure and server eligibility.
- Refresh queue state after success.
