BLUEBIRD MOBILE — ENABLE PRODUCTION CLERK SUPPORT

MODE: BUILD / EXECUTE

PRIORITY: CRITICAL — TESTFLIGHT

PROJECT: Bluebird Mobile

GOAL:

Implement proper Production Clerk
initialization in Bluebird Mobile.

The application currently supports
Development Clerk only.

Production Clerk environment selection
already exists, but ClerkProvider
does not use the selected Production key.

We need to support Production Clerk
for the upcoming iOS TestFlight build.

========================================
1. STRICT SCOPE
========================================

Modify Bluebird Mobile ONLY.

Main Bluebird Website/API is READ-ONLY.

Do not modify:

- Main API
- Main Website
- Database
- Membership records
- Clerk Dashboard
- Production accounts
- Shared backend packages

========================================
2. CLERK ENVIRONMENT SELECTION
========================================

Inspect the existing environment
selection implementation.

Use the selected Clerk publishable key
for ClerkProvider initialization.

Development:

EXPO_PUBLIC_BLUEBIRD_DEVELOPMENT_CLERK_PUBLISHABLE_KEY

Production:

EXPO_PUBLIC_BLUEBIRD_PRODUCTION_CLERK_PUBLISHABLE_KEY

Requirements:

- Development uses pk_test_ keys only.

- Production uses pk_live_ keys only.

- Never mix Development Clerk
  with Production API.

- Never mix Production Clerk
  with Development API.

- Never use the legacy
  EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY
  as a fallback.

- Missing or invalid configuration
  must fail closed.

========================================
3. PRODUCTION AUTH SUPPORT
========================================

Remove the Development-only restriction
that prevents Production ClerkProvider
from mounting.

Allow Production Clerk initialization
only when:

- API environment is production.

- A valid Production Clerk
  publishable key is configured.

- EXPO_PUBLIC_ENABLE_CLERK_AUTH=true.

- Required environment checks pass.

Do not bypass Clerk verification.

Do not bypass backend authorization.

Do not infer user identity from phone.

========================================
4. PRODUCTION API SAFETY
========================================

Use the existing verified Production API:

https://bluebirdjets.com/api

Do not change backend configuration.

Production API authentication acceptance
has not yet been verified.

Therefore:

- Do not automatically unlock
  membership or booking features.

- Do not treat Clerk sign-in as proof
  of Bluebird membership.

- Preserve the unresolved-member state
  until the real API confirms identity.

- Keep member-only actions blocked
  when API identity is unresolved.
