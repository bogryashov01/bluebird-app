PHASE 7 — PASSENGERS AND PETS

Implement the member passenger and pet methods
documented in the production contract.

Use Empty Leg scoped identifiers.

Use the actual passenger and pet schemas.

Important:

- Passenger and pet IDs are numeric.
- Weight is measured in pounds.
- Pet details use breed and weight.
- Passenger and pet PATCH bodies are not sparse.
- Passenger limits must be respected.
- Manifest locking must be respected.
- Lead passenger cannot be deleted.

CRITICAL:

GET /api/empty-legs/{id}/passengers
can create a lead passenger record.

Do not invoke this endpoint against production
during preparation or automated verification.
