CONTEXT:

Expo SDK 54.0.37 requires React 19.1.0.

Clerk's currently available dependency graph requires
React ~19.1.4, which Expo flags as unsupported.

The isolated React 19.1.4 experiment passed 31 tests
and web/iOS/Android bundling, but native runtime
compatibility remains unverified.

DECISION:

Keep the existing Expo and React versions.

Do not install Clerk yet.

GOAL:

Implement the parts of Stage 2A that do not depend
on the Clerk SDK.

- Do not change existing public API behavior.
- Do not commit or push.

STEP 1 — AUTHENTICATED API CLIENT

Create an isolated production API helper that accepts:

getToken: () => Promise<string | null>

Requirements:

- Reuse the existing production API base URL.
- Preserve production URL safety checks.
- Attach Authorization: Bearer <token>.
- Do not store or log tokens.
- Do not rely on browser cookies.
- Do not call authenticated endpoints automatically.

STEP 2 — GET /api/me

Implement an explicit function for:

GET /api/me

Requirements:

- Parse the production response.
- Validate isAuthenticated.
- HTTP 200 does not mean signed in.
- Treat isAuthenticated === false as signed out.
- Handle 401, network failures, timeouts, and invalid JSON.
- Do not invent user fields.
